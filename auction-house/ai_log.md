# AI Usage Log

## Tool Used
ChatGPT

## Usage Period
13.04.26 – 17.05.26

## Purpose
AI was used as a support tool during development of the AuctionHouse project. It was mainly used when I got stuck on TypeScript errors, API handling, and Bootstrap layout issues. AI was used for debugging help and explanations, not for building full features or generating finished code.

## What AI Was Used For

- Debugging TypeScript errors such as incorrect imports, missing types, and Vite-related issues
- Helping fix issues with string methods (e.g. replacing unsupported replaceAll() usage in some cases)
- Helping structure Bootstrap layouts, especially for responsive listing cards and grid layout and icons.
- Implementing and debugging the Bootstrap carousel for listing images (this was one of the more difficult parts of the project)
- Helping identify issues in authentication flow (login, API key handling, and storage logic)
- Clarifying how to interpret certain user stories and requirements in the assignment brief

## What AI Was NOT Used For

- No complete application or full pages were generated by AI
- No code was copied directly without testing or understanding
- All features were implemented and debugged manually after suggestions

## Notes

AI was mainly used when I got stuck or needed clarification during development. I treated it as a debugging assistant rather than a coding tool. All suggestions were tested, modified, and adapted before being added to the project.

Some parts of the project (especially the Bootstrap carousel and API data handling) required multiple iterations and manual debugging to work correctly.

## Compliance With AI Policy

AI was used within the allowed guidelines for the assignment. It was primarily used for explanations, debugging assistance, code structure suggestions, and clarification of frontend concepts. All final code was reviewed, tested, and adapted manually. No code was submitted without understanding how it worked.
