# AuctionHouse

AuctionHouse is a student auction web application built for the Noroff Semester Project 2 assignment. The application allows visitors to browse and search auction listings, while registered users can create listings, place bids, manage their profiles, and view their credits.

## Features

- Browse auction listings without logging in
- Search and filter listings
- View a single listing with details and bid history
- Register using a `@stud.noroff.no` email
- Log in and log out
- View credits while logged in
- Create auction listings
- Add multiple images to listings
- Edit and delete own listings
- Place bids on other users’ listings
- View profile with avatar, banner, bio, listings, bids and credits
- Responsive layout for desktop and mobile
